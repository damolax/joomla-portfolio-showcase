# Joomla Portfolio Showcase

A single repository for independent website demo projects. The production Vercel project serves the `docs/` folder.

## AUREL Studio — architecture/interiors portfolio concept
Live: https://joomla-portfolio-showcase.vercel.app/aurel-studio/

Features: complete responsive site pages, six separate architecture/interior design studies with lightbox galleries, six long-form journal articles, site-wide search, journal and project search, material swatches with category filters and copy, five-stage process, engagement models, FAQ, local-only contact draft creation and downloadable project briefs.

The custom SVG studio mark is used in the header, footer and favicon. The website uses accessible navigation, focused controls and reduced-motion styling.

**Implementation:** HTML/CSS/JS live demonstration (static). The Joomla template foundation lives under `source/joomla/aurel-studio/template`. A working PHP/MySQL-backed Joomla CMS, backend submissions and outbound email remain separate deployment tasks. AUREL is a fictional concept: project images, team descriptions and engagement models are illustrations, not commissioned-client claims.
