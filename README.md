# Joomla Portfolio Showcase
Public interactive demonstrations of Joomla-ready website concepts. The /docs directory is a deployable static website, with each project at its own URL.
## Demo 01
AUREL Studio: docs/aurel-studio/index.html (13 HTML pages plus shared assets).
## Structure
- docs/index.html — portfolio landing
- docs/aurel-studio/ — multi-page demo website
- source/joomla/aurel-studio/ — source notes and Joomla template scaffold
## Important
These hosted demos use HTML/CSS/JavaScript. They are not functioning Joomla CMS installations. PHP, a database, content management and mail require separate Joomla hosting.
